# Turkish language NLP projects

Two independent Turkish NLP projects. Each directory contains one maintained code version and its own documentation.

| Project | Scope | Status |
|---|---|---|
| [PII detection and redaction](turkish-pii-redaction/README.md) | Span detection, identifier validation, redaction, benchmark analysis | Kaggle run completed; execution record included |
| [Aspect based sentiment analysis](turkish-absa/README.md) | Aspect extraction, polarity, data audit, Colab training | Data preparation checked; GPU training and model evaluation pending |

The PII external test does not establish a clear improvement over the evaluated baseline. The ABSA project reports no accuracy until full model training is complete. Each project README explains the evidence and limits.
